🎯 Filosofía del diseño

🔴 ORIGEN — Google Drive Compartidos
📖 Solo LECTURA de metadata
🚫 No se descargan archivos
🚫 No se elimina nada
🚫 No se modifica ningún nombre
🧐 Múltiples carpetas por técnico/fecha
⚠️ Espejo intacto de lo que subieron los usuarios
🟢 DATOS — Google Sheets (Base de Datos)
📊 Catálogo maestro NIS→SGIO→DESTINO
📁 Registro de N carpetas activas (FOLDERS)
✅ Estado de cada imagen (✅/⬜) por carpeta
🔢 Cantidad real sumando todas las carpetas
🧩 Deduplicación: mismo NIS en varias carpetas
📋 LOGS de cada operación
🌐 Accesible desde el navegador o desde la app
✅ Fuente única de verdad — editable desde la UI del Sheet
🔑
La regla de oro (v4):
REGISTRAR(carpetas) → LEER(Drive multi-carpeta) → CONTAR → DEDUP → MATCH(NIS→SGIO) → ESCRIBIR(Google Sheets)

No se suben archivos a ningún lado. Las imágenes nunca salen de Compartidos. Se lee su metadata (nombre, fecha) de todas las carpetas registradas, se deduplican NIS, y se actualiza el Sheet como única fuente de verdad.

🧩 Lógica de procesamiento (multi-carpeta)

// Paso 0: Leer carpetas activas desde FOLDERS del Sheet
folders = Sheets.read("FOLDERS!A:B") // solo las ACTIVAS
// → [{ name: "TECNICO_JUAN", folder_id: "1abc123..." }, ...]

// Paso 1: Escaneas TODAS las carpetas activas
raw_results = []
for folder in folders:
  emit("autoimg.scan.folder_start", { folder: folder.name, index: i, total: folders.length })
  archivos = Drive.files.list({ q: "'{folder_id}' in parents and mimeType contains 'image'" })
  for archivo in archivos:
    nis = regex(/\b(\d{7})\b/, archivo.name)
    raw_results.push({ nis, file: archivo.name, folder: folder.name })
  emit("autoimg.scan.folder_done", { folder: folder.name, count: archivos.length })

// Paso 2: Deduplicar — agrupar por NIS, sumar carpetas
nis_map = {}
for r in raw_results:
  nis_map[r.nis] = nis_map[r.nis] || { count: 0, folders: [], files: [] }
  nis_map[r.nis].count += 1
  nis_map[r.nis].folders.add(r.folder) // ← dedup multi-carpeta
  nis_map[r.nis].files.push(r.file)

// Paso 3: Cruzar vs BD_IMG del Sheet
sheet_data = Sheets.read("BD_IMG!A:M")
for each nis in nis_map:
  match = sheet_data.find(row => row.nis === nis)
  cantidad = nis_map[nis].count
  origen = nis_map[nis].folders.join("; ")
  if match:
    update = {
      CANTIDAD: cantidad,
      IMG_1: cantidad >= 1 ? "✅" : "⬜",
      IMG_2: cantidad >= 2 ? "✅" : "⬜",
      IMG_3: cantidad >= 3 ? "✅" : "⬜",
      ESTADO: cantidad == 3 ? "🟢 COMPLETO" : cantidad < 3 ? "🔴 FALTANTE" : "🟡 SOBRANTE",
      ORIGEN: origen,
      ÚLTIMA_VERIFICACIÓN: "2026-07-02 14:30"
    }
    Sheets.write("BD_IMG!F" + match.row, update) // batch write
🔍 Solo metadata — nunca el contenido
La app nunca descarga las imágenes. Solo lee: name, modifiedTime, id. Escaneas 1000 archivos en 3 carpetas toma ~5 segundos. ✅ Solo 1 fila por NIS en BD_IMG, aunque aparezca en N carpetas.

🔌 API IPC — Métodos

// ─── Google Sheets Auth ──────────────────────────
autoimg_sheets_auth_url → { url: string }
autoimg_sheets_auth_callback → { success: boolean }
autoimg_sheets_auth_status → { authenticated, email? }
autoimg_sheets_auth_revoke → { success: boolean }

// ─── Google Sheets CRUD ─────────────────────────
autoimg_sheets_open → open Sheet by ID
autoimg_sheets_read_range → { values: any[][] }
autoimg_sheets_write_range → { updated: number }
autoimg_sheets_append_row → append to range

// ─── Drive Scanner ──────────────────────────────
autoimg_drive_list_folder → list files (metadata only)
autoimg_drive_scan_nis → scan + extract NIS from folder

// ─── Gestión de Carpetas (v4 new) ─────────────────
autoimg_folders_list → carpetas registradas
autoimg_folders_add → agregar carpeta activa
autoimg_folders_remove → quitar carpeta
autoimg_folders_toggle → activar/desactivar

// ─── Core Sync (v4 enhanced) ─────────────────────
autoimg_scan_all → escanear TODAS las carpetas activas
autoimg_sync_to_sheet → escribir resultados al Sheet
autoimg_sync_from_sheet → leer Sheet → refrescar UI
autoimg_auto_sync_toggle → ON/OFF auto-sync
autoimg_status → estado general + métricas
